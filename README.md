<h2>🧐 Features</h2>

Here're some of the project's best features:

*   Rename All Files In A Directory
*   Rename All Files In Diectory With Specific Extension
*   Delete All Empty Subdirectories In A Directory

<h2>🛠️ Installation Steps:</h2>

<p>1. Clone this project</p>

```
git clone https://github.com/PavinDas/File-Operators
```

<p>2. Open project folder</p>

```
cd File-Operators
```

<p>3. Run the script</p>

```
python  file_operators.py
```
